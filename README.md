## 📖 Course Description & Overview

The **Mastering NestJS** course provides an end-to-end deep dive into building enterprise-grade, scalable, and maintainable backend applications using TypeScript and Node.js.

Key topics and concepts covered in this repository include:

- **Core Architecture:** Controllers, Providers, Services, Modules, Dependency Injection, Custom Decorators, Pipes, Guards, and Interceptors.
- **API Paradigms:** Building robust REST APIs and GraphQL interfaces.
- **Authentication & Security:** JWT authentication flows, OAuth integrations, Role-Based Access Control (RBAC), and request validation via Class-Validator.
- **Database Integration & ORMs:** Schema design, dynamic migrations, and repository patterns using TypeORM and Prisma with relational databases.
- **Event-Driven & Microservices Architecture:** Decoupled microservices messaging using TCP, RabbitMQ, and event emitters.
- **Quality Assurance & DevOps:** Unit and end-to-end (E2E) testing with Jest and Supertest, containerization via Docker, and automated CI/CD deployment pipelines.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:

Node.js (>=18.x)

npm or pnpm

Docker

NestJS CLI: npm i -g @nestjs/cli

## Installation & Local Setup

- Clone the repository:

`git clone https://github.com/hasheddev/nestjs-masterclass-course.git`

`cd nestjs-masterclass-course`

- Navigate to a specific project module:

`cd module`

- Install dependencies:

`npm install`

- Environment Configuration:

fill in the required credentials

- Run Database Container (if applicable)

- Start the NestJS Development Server

`npm run start`
